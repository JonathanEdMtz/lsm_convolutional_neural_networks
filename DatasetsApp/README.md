# DataApp

Módulo para recolectar imágenes del abecedario en Lengua de Señas Mexicana (LSM) mediante la cámara web para armar el dataset.

## Uso

```bash
python DataApp/dataset_lsm.py
```

## Controles

* **ESPACIO**: Captura las fotos de la seña actual.
* **ESC**: Salta a la siguiente seña.

## Salida

Las fotos capturadas se guardan automáticamente en la carpeta `data/data_recolection/<clase>/`.
